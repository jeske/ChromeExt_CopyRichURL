Copy Rich URL

What it does

This extension copies the current page's URL and Title as a rich HTML link. When you paste it into a rich text editor (like Outlook, Word, or Slack), it will appear as a clickable link: <a href="...">Title</a>.

How to use

  1. Click the extension icon in the toolbar
  2. Click the "Copy Current URL" button in the popup
  3. Paste into any rich text editor

Why a popup with a button?

Chrome's Clipboard API requires user activation (a user gesture like a click) to write rich HTML content to the clipboard. This is a security feature to prevent malicious extensions from silently modifying your clipboard.

The popup button provides this user activation. Without it, we would need to request scripting permission to inject code into every page you visit (a security risk), or use deprecated/unreliable clipboard methods.

This popup approach is the cleanest, most secure solution that works reliably across all websites.
