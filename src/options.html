Copy Rich URL

What it does

This extension copies the current page's URL and Title as a rich HTML link. When you paste it into a rich text editor (like Outlook, Word, or Slack), it will appear as a clickable link: Title.

How to use

  • Click the extension icon in the toolbar.
  • Right-click anywhere on a page and select Copy Rich URL.
  • Use the keyboard shortcut (configurable below).

Keyboard Shortcut

You can configure a custom keyboard shortcut to copy the rich URL instantly.
